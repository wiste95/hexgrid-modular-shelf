# hexgrid-modular-shelf
HexGrid Modular Shelf System — Configurator

A browser-based visual configurator for the HexGrid Modular Shelf System, a fully modular 3D-printable shelf system built around a 200×200mm grid.

Usage

Download configurator_modular_organizer_shelf.html and open it in any browser. No installation required, no internet connection needed, no data is sent anywhere. You can inspect the full source code directly in any text editor.

What it does

Place Plates (200mm) and Small Plates (94.5mm) on a grid by clicking edges
Add Diagonal Braces per corner cell
Connectors and Feet are calculated automatically based on how many plates meet at each point
Generates a full parts list including estimated filament weight
